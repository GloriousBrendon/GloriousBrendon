### `$ whoami`

Self-taught engineer who started out as an IT tech and graphic designer and never stopped taking things apart. These days I engineer by day and build my own tools by night, usually because the off-the-shelf option broke, phoned home, or just annoyed me.

Linux on the desktop, Docker in the cupboard, distortion in the headphones. 🤘

```yaml
role:        Senior Lead Software Engineer
daily_driver: CachyOS + Hyprland (Wayland) · fish · VS Code + Claude Code
rig:         Ryzen 7 7700X · RX 7800 XT · 32GB DDR5
philosophy:  "If it doesn't exist, build it. If it's broken, reverse-engineer it."
off_hours:   Frontman, guitarist & in-house producer for Nagbreek (Afrikaans punk)
```

### 🔨 Things I've built & am building

| Project | What it is | Stack |
|:--|:--|:--|
| 🎛️ **[Live Set Player](https://github.com/GloriousBrendon/live-set-player)** | Gig-ready playback app for live performance — offline render, synthesized click with count-in, TTS cue announcements, MIDI footswitch control. 143 tests, CI on Linux + Windows. | Tauri 2 · Rust · Svelte |
| ⌨️ **CNTRL** | Native Linux control app for my Hall Effect keyboard after the vendor's web configurator broke. Reverse-engineered the HID protocol from `usbmon` captures; RGB syncs with my Hyprland theme. | Rust · Iced · HID |
| 🏰 **7KAA Remaster** | Modernising *Seven Kingdoms: Ancient Adversaries* (~225K lines of C++) — frame pacing, vsync, scaling filters — while keeping gameplay deterministic and every commit upstreamable. | C++11 · SDL |
| 🛡️ **Untitled Anti-Cheat** | Open-source, **non-kernel** anti-cheat, so Linux and Steam Deck players stop getting locked out of games. Early days. 👀 | TBA |
| 🏠 **Homelab** | Self-hosted everything: Nextcloud, Matrix/Synapse, SearXNG, Pi-hole, Steam LanCache, all fronted by Caddy and reached over Tailscale. | Docker · Caddy · Linux |
| 🚀 **Deploy platform** *(work)* | Internal CI/CD dashboard that killed manual deployments — build-once-promote via image digests, rollback snapshots, per-environment deploy locks. | .NET · Docker · GHCR |
